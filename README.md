# 🪵 คำนวณราคาไม้

เว็บแอปคำนวณราคาไม้ ใช้สูตร

```
หนา (นิ้ว) × กว้าง (นิ้ว) × ยาว (เมตร) × 0.0228 × ราคาต่อคิว
```

- สลับได้ระหว่างไม้ยางกับไม้เต็ง
- ปุ่มลัดสำหรับความหนาและความกว้าง
- แก้ราคาต่อคิวได้ และกด "บันทึกเป็นค่าเริ่มต้น" ได้ (ราคาเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น)
- เพิ่มหลายรายการ รวมยอด แล้วคัดลอกไปส่งลูกค้าได้
- ติดตั้งลงหน้าจอมือถือเป็นแอปได้ และเปิดได้แม้ไม่มีอินเทอร์เน็ต

## เปิดใช้งานบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `wood-calc`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ตรง **Source** เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` กด **Save**
5. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/wood-calc/`

## ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"

## แก้ราคาตั้งต้นหรือชนิดไม้

แก้ในไฟล์ `index.html` ตรงตัวแปร `TYPES` (ราคา, ชื่อ, หมายเหตุ) และ `FIELDS` (ปุ่มลัดหนา/กว้าง)

หลังแก้ไฟล์ ให้เปลี่ยนชื่อ cache ใน `sw.js` (เช่น `woodcalc-v1` → `woodcalc-v2`) เพื่อให้มือถือที่ติดตั้งไว้โหลดเวอร์ชันใหม่

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.json` | ข้อมูลสำหรับติดตั้งเป็นแอป |
| `sw.js` | ให้แอปเปิดได้ตอนออฟไลน์ |
| `icon.svg`, `icon-192.png`, `icon-512.png` | ไอคอนแอป |
